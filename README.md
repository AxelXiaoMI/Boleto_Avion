# Primer Proyecto 

Aporto a la comunidad mi primer proyecto basico de Python en donde simulo la compra de un ticket de avion, donde obtengo datos introducidos por el usuario
como el destino que eligio, la cantidad de personas que viajan y datos de cada pasajero (Nombre, DNI, Nacionalidad) y una vez que los obtengo verifico que sean
del tipo de dato correcto y que cumplan con el formato que pido para luego insertarlos a la base de datos usando la libreria PSYCOPG2 que es para conectar POSTGREDSQL
